# Aervalon — Vertical Slice 0.1

Primeira build jogável do Vale de Eryndor em Godot 4.x.

## Meta da 0.1
Provar o loop: explorar → combater → coletar → evoluir → retornar à vila.

## Implementado nesta fundação
- Projeto Godot 4, renderer GL Compatibility (web/mobile friendly)
- Vale de Eryndor como primeira cena
- Personagem controlável com câmera suave
- Movimento WASD/setas
- Ataque corpo a corpo
- Lobos com aggro, perseguição, dano e morte
- Vila, rio e Floresta Sussurrante como blockout visual

Os polígonos são placeholders deliberados. A próxima etapa substitui o blockout por arte/tiles, adiciona colisões do mundo, NPCs vivos, coleta, loot e UI mobile.

## Rodar
Abra project.godot no Godot 4.x e pressione F6/F5.
