# Classes V0.1

A classe é uma escolha persistente do personagem e define arma, ritmo e habilidade. A raça continua sendo origem/cultura; classe não substitui raça.

Classes aprovadas:
- Guardião — espada/machado/maça + escudo; Bastião, Conquistador, Vanguarda.
- Sombra — duas adagas/espadas curtas; Assassino, Veneno, Espectro.
- Rastreador — arco/besta/rifle + faca/pet; Atirador, Domador, Caçador.
- Arcanista — cajado/varinha + grimório; Chama, Gelo, Arcano.
- Luminar — maça/escudo, martelo ou cetro + livro; Graça, Juramento, Julgamento.
- Vinculado — cajado/lança/foice + talismã; Fera, Vida, Espírito.
- Velário — cajado/adaga/foice; Ossos, Ecos, Sangue.
- Artífice — pistola/rifle + ferramenta/dispositivo; Artilheiro, Mecânico, Demolidor.
- Tempestário — lança/machado/martelo + foco; Tempestade, Terra, Maré.
- Ecoante — lâmina/bastão + foco; Tempo, Memória, Ruptura.

Nesta etapa, as dez classes já podem ser escolhidas na criação, persistem no roster, recebem arma inicial compatível, alteram atributos/ritmo de combate e possuem um poder ativo em Q / botão mobile. Especializações ainda não são selecionáveis e a arte segurando cada família de arma continua sendo uma próxima camada visual.
